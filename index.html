Politique de confidentialité — PhpNitro Go

Dernière mise à jour : 22 août 2026

PhpNitro Go (com.phpnitro.go) est une application compagnon pour les développeurs utilisant PhpNitro, un framework open source pour créer des applications mobiles en PHP. Elle sert uniquement à prévisualiser, sur un vrai appareil, l'écran natif d'un projet PhpNitro en cours de développement — sans qu'aucun code de ce projet ne soit jamais intégré à l'application elle-même.

Ce que l'application fait réellement

Au lancement, PhpNitro Go affiche un écran pour saisir ou scanner (via appareil photo) l'adresse d'un serveur de développement local (typiquement phpx serve, tournant sur le même réseau Wi-Fi que ton ordinateur). Une fois connectée, elle envoie de simples requêtes HTTP à ce serveur et affiche les commandes de dessin qu'il renvoie — exactement comme si le code de ton projet tournait directement sur l'appareil.

Permissions demandées

  • Appareil photo — uniquement pour scanner le QR code affiché par ton serveur de développement (adresse IP + port). L'image de l'appareil photo est traitée entièrement sur l'appareil (décodage de code-barres via ML Kit, hors ligne) et n'est jamais enregistrée, envoyée à un serveur, ni partagée avec qui que ce soit — y compris avec les auteurs de PhpNitro.
  • Réseau (Internet/réseau local) — utilisé uniquement pour parler au serveur de développement dont TU saisis ou scannes l'adresse. Aucun serveur exploité par PhpNitro ou ses auteurs n'est jamais contacté par l'application elle-même.

Ce que l'application ne fait pas

  • Aucun compte utilisateur, aucune authentification.
  • Aucune analytique, aucun outil de suivi, aucun SDK publicitaire.
  • Aucune donnée personnelle collectée, stockée ou transmise par l'application à un serveur tiers.
  • Aucun code de projet embarqué — l'application ne fait qu'afficher ce que TON propre serveur de développement lui envoie.

Une nuance importante

PhpNitro Go affiche l'écran que renvoie le serveur auquel tu la connectes — c'est-à-dire ton propre projet, en cours de développement, sur ta propre machine. Si cet écran-là demande explicitement une autre permission (par exemple, la biométrie ou la localisation, si le projet PhpNitro connecté utilise ces fonctionnalités), Android te la demandera au moment voulu, de façon habituelle — mais PhpNitro Go elle-même ne déclare et ne demande jamais ce genre de permission : seules l'appareil photo et le réseau, listés ci-dessus, sont réellement inclus dans cette application.
